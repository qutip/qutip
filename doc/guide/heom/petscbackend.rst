#############
PETSc Backend
#############

The `PETSc <https://petsc.org/>`_ backend for QuTiP's Hierarchical Equations of
Motion (HEOM) solver enables large-scale, distributed open quantum system
simulations. By leveraging ``petsc4py`` and ``mpi4py``, it allows you to run
computationally heavy HEOM problems in parallel across multiple MPI ranks.

Key capabilities of this backend include:

- **Distributed Matrix Assembly**: The HEOM Liouvillian is distributed across
  MPI ranks, overcoming the memory limits of a single machine.
- **Parallel ODE Integration (TS)**: Time evolution utilises PETSc's Time Stepping
  module, providing robust implicit solvers (like BDF) for stiff ODEs.
- **Steady-State Solving (KSP)**: Direct steady-state calculations utilise
  PETSc's Krylov Subspace iterative linear solvers.

.. warning::

   The PETSc backend currently supports **time-independent** Hamiltonians only.
   Passing a time-dependent ``H`` or ``QobjEvo`` with non-trivial time dependence
   will raise a ``NotImplementedError``.

Initialization and Time Evolution
----------------------------------

Enable the PETSc backend by passing ``backend="petsc"`` to
:class:`~qutip.solver.heom.HEOMSolver`.

.. code-block:: python

    from qutip.solver.heom import HEOMSolver

    # Initialize PETSc backend solver
    solver = HEOMSolver(H_sys, bath, max_depth=max_depth, backend="petsc")

    # Run the dynamics in parallel
    result = solver.run(rho0, tlist)

Because the coupled ordinary differential equations generated by HEOM are
typically stiff, the default PETSc integrator is the Backward Differentiation
Formula (BDF). You can customise the internal PETSc routines using the standard
``"method"`` option key (which maps to PETSc's ``ts_type``), along with
additional PETSc-specific keys:

.. code-block:: python

    options = {
        "method": "bdf",        # ODE time-stepping method (maps to PETSc ts_type)
        "ts_adapt": "basic",    # Adaptive step-size controller
        "dt": 1e-4,             # Initial time step
        "max_steps": 100000,    # Maximum number of steps
        "atol": 1e-8,           # Absolute tolerance
        "rtol": 1e-6,           # Relative tolerance
    }

    solver = HEOMSolver(H_sys, baths, max_depth=6, backend="petsc", options=options)

**Supported values for** ``method`` **(PETSc** ``ts_type`` **)**:

``"bdf"``
    Backward Differentiation Formula (default) — recommended for stiff HEOM systems.

``"cn"``
    Crank-Nicolson — second-order, A-stable.

``"beuler"``
    Backward Euler — first-order, very stable.

``"rk"``
    Explicit Runge-Kutta — not recommended for stiff systems.

For the complete list see the
`PETSc TS documentation <https://petsc.org/release/manual/ts/>`_.

**Additional PETSc-specific integrator options:**

``ts_adapt`` (default: ``"basic"``)
    Step-size controller. Use ``"none"`` to disable adaptivity.

``dt`` (default: ``1e-4``)
    Initial time step.

``max_steps`` (default: ``100000``)
    Maximum number of time-stepping iterations.

``ksp_type`` (default: ``"bcgs"``)
    Krylov method for the internal linear solver (``"bcgs"``, ``"gmres"``, ...).

``pc_type`` (default: ``"bjacobi"``)
    Preconditioner type (``"bjacobi"``, ``"ilu"``, ``"none"``, ...).

``ksp_atol`` (default: ``1e-8``)
    Absolute tolerance for KSP.

``ksp_rtol`` (default: ``1e-6``)
    Relative tolerance for KSP.

``store_ados`` (default: ``False``)
    Gather and store full ADO state at each output time (increases memory/communication).

Steady-State Solutions
----------------------

Evolving stiff HEOM systems to :math:`t \rightarrow \infty` can be
prohibitively slow. Instead, you can directly compute the steady state
:math:`\mathcal{L} \vec{\rho}_{heom} = 0` using parallelised PETSc KSP
solvers:

.. code-block:: python

    steady_state, steady_ados = solver.steady_state(
        ksp_type="gmres",   # Krylov Subspace method (e.g. 'gmres', 'bcgs')
        pc_type="none",     # Preconditioner type
        ksp_rtol=1e-8,
        ksp_atol=1e-8,
    )

Running with MPI
----------------

To fully utilise the PETSc backend, your scripts must be executed using an MPI
launcher (e.g., ``mpiexec``, ``mpirun``, or ``srun``) with the standard
Python interpreter. PETSc seamlessly handles the distribution of matrix rows
across the entire MPI communicator.

For example, to run a script on 4 local cores:

.. code-block:: bash

    mpirun -np 4 python heom_petsc_example.py

**SLURM Cluster Example:**

When deploying on high-performance computing clusters using a workload manager
like SLURM, you can distribute your HEOM simulations across multiple nodes:

.. code-block:: bash

    #!/bin/bash
    #SBATCH --nodes=4
    #SBATCH --ntasks=64
    #SBATCH --time=0-05:00:00

    module load mpi/mpich-x86_64 petsc
    conda activate qutip-env

    mpirun -np $SLURM_NTASKS python heom_petsc_example.py

Complete Example
----------------

Below is a complete, deployable script demonstrating a 1D Ising spin chain
coupled to a Drude-Lorentz bath. This highlights the typical structure of an
MPI-aware QuTiP HEOM script, ensuring outputs are only printed from the root
rank.

.. code-block:: python

    import numpy as np
    from mpi4py import MPI
    import qutip as qt
    from qutip.solver.heom import HEOMSolver, DrudeLorentzBath

    def run_simulation():
        comm = MPI.COMM_WORLD
        rank = comm.Get_rank()

        def print0(*args):
            """Helper to print only on the root MPI rank."""
            if rank == 0:
                print(*args, flush=True)

        # 1. System Parameters (2-Spin Ising Model)
        N = 2
        g0, J0 = 1.0, 1.4

        sx_list, sz_list = [], []
        for i in range(N):
            op_list = [qt.qeye(2)] * N
            op_list[i] = qt.sigmax()
            sx_list.append(qt.tensor(op_list))

            op_list[i] = qt.sigmaz()
            sz_list.append(qt.tensor(op_list))

        H = sum([g0 * sz_list[i] for i in range(N)])
        H += sum([-J0 * sx_list[n] * sx_list[n + 1] for n in range(N - 1)])

        # 2. Define the bath on the first spin
        baths = [DrudeLorentzBath(
            Q=sz_list[0],
            lam=0.01,
            gamma=1.0,
            T=1.0,
            Nk=4,
        )]

        psi0 = qt.tensor([qt.basis(2, 0)] * N)
        rho0 = qt.ket2dm(psi0)

        # 3. Set up the HEOM solver with the PETSc backend
        print0("Setting up HEOM solver...")

        options = {
            "method": "bdf",      # ODE method (maps to PETSc ts_type)
            "ts_adapt": "basic",
            "atol": 1e-8,
            "rtol": 1e-8,
        }

        solver = HEOMSolver(H, baths, max_depth=6, backend="petsc", options=options)
        if comm is not None:
            comm.Barrier()

        # 4. Run the parallel evolution
        tlist = np.linspace(0, 10, 50)
        e_ops = [sz_list[-1]]

        print0(f"Running evolution with {comm.Get_size()} MPI processes...")
        result = solver.run(rho0, tlist, e_ops=e_ops)

        # 5. Output results
        print0("Final expectation value:", result.expect[0][-1])

    if __name__ == "__main__":
        run_simulation()
